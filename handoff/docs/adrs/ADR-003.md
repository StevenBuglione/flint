# ADR-003: Enable DIP1000 and make borrowed APIs explicit

Status: accepted design for the implementation handoff; date: 2026-11-21.

## Context

Safe arenas and callbacks require enforceable escape constraints, despite additional annotations. @safe by itself does not establish an arbitrary arena reset lifetime.

## Decision

Enable -preview=dip1000 on all code. Use ref scope for borrowed arena/context parameters and scope implicit this for borrower methods. Use return scope only when an intentional returned borrow must remain tied to its owner. Named examples and compiler-negative tests define the canonical syntax.

## Alternatives and consequences

Disabling DIP1000 for convenience was rejected. It would move ordinary lifetime mistakes into manual review. There remains a trusted boundary whose obligations are not discharged by the compiler.

## Acceptance evidence

A callback that stores a borrowed slice globally and a function returning stack-backed arena storage must fail under both compilers. Valid caller-owned paths pass.
