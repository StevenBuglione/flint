# ADR-004: Use generation-checked arena handles

Status: accepted design for the implementation handoff; date: 2026-11-21.

## Context

A retained slice can outlive reset even if its original allocation method was marked safe. An index-only handle can also become a different allocation after reuse.

## Decision

Buffer/Text carry arena identity, generation and bounded location. Every access validates identity/generation/length. Scoped visitor callbacks expose temporary slices. Reset refuses outstanding borrows; generation exhaustion permanently retires the arena. Private constructors reduce accidental forging, and validation still rejects .init/foreign handles.

## Alternatives and consequences

Raw slices remain inside tiny audited low-level operations. Fast-path arithmetic and generation checks have a real cost that benchmarks must include. Do not remove them to meet a goal.

## Acceptance evidence

Fuzz stale/foreign/wrapped handles; test overflow/exact fit/unaligned storage; reject escaped views; run allocator tests under ASan.
