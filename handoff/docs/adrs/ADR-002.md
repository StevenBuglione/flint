# ADR-002: Keep 37 DUB subpackages and an explicit acyclic graph

Status: accepted design for the implementation handoff; date: 2026-11-21.

## Context

A root targetType none does not build/test all subpackages. Numeric tiers alone also conflict with web wanting a Tier 8 codec.

## Decision

Keep the requested catalog tiers and independent library recipes. policy/packages.json is the direct-dependency allowlist. The application passes codec/template/security adapters into lower-tier interfaces. Orchestrator builds affected reverse dependents in topological order.

## Alternatives and consequences

No aggregate sourceLibrary importing everything. A shared source root or transitive accidental imports would invalidate package isolation. Application composition contains a little more wiring.

## Acceptance evidence

Parse every recipe with DUB; reject cycles, unknown imports and CLI-to-web/data imports; compare source/descriptor dependencies.
