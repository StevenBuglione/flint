# ADR-007: Generate only from explicitly registered types

Status: accepted design for the implementation handoff; date: 2026-11-21.

## Context

UDAs are metadata, not runtime interception or classpath scanning. Unbounded compile-time symbol traversal threatens both predictability and build budgets.

## Decision

AppContext consumes explicit beans/bindings. Controllers and clients are registered explicitly. Bound registries to 128 beans/256 routes/128 DTO fields/256 client methods per generation unit. Materialize larger generated units deterministically, with explicit imports and checked hashes.

## Alternatives and consequences

Runtime scanning/proxies and metaprogramming in business code were rejected. A direct method call bypasses generated transaction/auth/retry wrappers unless the caller explicitly invokes them.

## Acceptance evidence

Compile-fail missing bindings/cycles/duplicate routes; assert deterministic generated output; record template contexts, trace and RSS.
