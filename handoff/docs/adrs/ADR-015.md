# ADR-015: Make preparation evidence separate from implemented behavior

Status: accepted design for the implementation handoff; date: 2026-11-21.

## Context

A handoff can typecheck declarations and examples before a framework exists, but unresolved declarations cannot prove runtime semantics or performance.

## Decision

Keep contracts outside production scaffolding. Verify syntax with real compilers, validate manifests/scripts and run standalone Go/WASM/tooling tests. Label every receipt by scope. Full package behavior and all-platform performance belong to implementation milestones.

## Alternatives and consequences

No always-success functions, fake benchmarks, fabricated baselines or claim that the archive is an working 37-package framework. Honest remaining runtime work is specified with exact tests and commands.

## Acceptance evidence

Archive checker rejects missing specs/links/recipes, compiler probes check APIs, source-free orchestrator targets fail, and release evidence cannot be substituted with typecheck receipts.
