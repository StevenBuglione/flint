# ADR-009: Normalize C ABI before ImportC

Status: accepted design for the implementation handoff; date: 2026-11-21.

## Context

Vendor headers contain target-specific macros, bitfields, callbacks and C++ types. Blind translation can create platform ABI bugs.

## Decision

Expose small Flint C shims with fixed-width scalars, byte spans, opaque pointers, explicit release functions and synchronous status returns. Bind those in private extern(C) modules; optionally compile normalized headers with ImportC. C and D layout probes are target-native tests.

## Alternatives and consequences

Direct wholesale header import is not the default. No exceptions or GC allocations cross C callbacks; callback registration owns its userdata until final deregistration/completion.

## Acceptance evidence

Compare sizeof/alignof/offsetof and enum values; test callback calling conventions, nulls, zero lengths, early errors and double destroy defenses under sanitizers.
