# ADR-014: Pin MCP transport behavior and provider schemas

Status: accepted design for the implementation handoff; date: 2026-11-21.

## Context

Current MCP Streamable HTTP differs from older session/GET-based examples. LLM vendors also expose distinct request/stream semantics.

## Decision

Default MCP mode is 2026-07-28 with a separate 2025-11-25 compatibility state machine. Validate version/header/body agreement, origin, auth and framing limits. Provider adapters expose supported capabilities and reject unsupported settings rather than silently losing them.

## Alternatives and consequences

No universal implicit provider conversion, no model-name assumptions, and no mixing lifecycle messages from different protocol versions. Tool dispatch validates schema and authorization before invoking application code.

## Acceptance evidence

Conformance fixtures cover framing/cancellation/version errors/MRTR, multi-byte SSE boundaries, retries, duplicate tool IDs and no stdout logs on stdio.
