# ADR-012: Correct quality flags and retain sanitizer coverage limits

Status: accepted design for the implementation handoff; date: 2026-11-21.

## Context

The requested dfmt --check and LDC undefined-sanitizer assumptions do not match installed tools.

## Decision

Pin dfmt/D-Scanner 0.15.2. Compare formatter stdout with input bytes. Parse D-Scanner findings even when report exits zero. D code runs ASan; C shims run Clang ASan+UBSan. Fuzz boundary parsers and execute negative @safe/DIP1000 tests.

## Alternatives and consequences

Do not silently skip unsupported flags or call a C UBSan result a proof of D undefined-behavior coverage. Full formatter/linter code review is still needed for generated code.

## Acceptance evidence

Actual tool-help/probe receipts identify supported flags; intentional bad formatting/unused variables/missing safety comments and lifetime escapes fail.
