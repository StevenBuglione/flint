# ADR-010: Build static musl with a matching runtime closure

Status: accepted design for the implementation handoff; date: 2026-11-21.

## Context

Switching the final linker cannot transform glibc-built druntime/Phobos/native libraries into musl libraries.

## Decision

Use exact official Alpine LDC archives and build the whole C closure for musl on matching architecture runners. Linux glibc uses its own closure. Native compiler drivers handle CRT startup. The verified Linux ThinLTO path is the default system `cc`/`ld` plus the official LDC archive's bundled `LLVMgold-ldc.so` plugin; O3 and Oz executables linked and ran. External matching LLD22 is optional. Native `-link-internally` failed CRT lookup in the tested environment and is excluded from the native recipe. Browser freestanding WASM uses LDC internal LLD. macOS/Windows system frameworks follow OS linking rules.

## Alternatives and consequences

A universal zig cc shortcut and unverified static claims were rejected. Zig may be an explicitly tested compiler driver for C shims later, not a substitute for target runtimes.

## Acceptance evidence

Inspect Linux PT_INTERP/DT_NEEDED, run in an empty runtime container, verify architecture, and compare deployed bytes. Cross-compiling without running is not runtime acceptance. [Observed native ThinLTO receipt](../../verification/native-thinlto.json) records the successful default-linker probes separately from unsupported native internal-linker flags.
