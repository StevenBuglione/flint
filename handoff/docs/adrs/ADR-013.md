# ADR-013: Treat dependency licenses and optional UI backends as profiles

Status: accepted design for the implementation handoff; date: 2026-11-21.

## Context

Top-level permissive licenses do not automatically cover transitive compression/auth/UI components. WebKitGTK does not match a permissive-only default.

## Decision

Pin source commits/archive digests/license text. Choose permissive alternatives explicitly where dual-licensed. Keep optional codecs, plugin engines and desktop backends separate. SDL3 is the permissive default; WebKitGTK is excluded from that profile. System webviews have additional OS/runtime terms.

## Alternatives and consequences

No blanket assertion that every optional platform component is MIT. Source pinning is reproducibility, not independent security-signature verification or legal clearance.

## Acceptance evidence

Generate BOM of actual linked closure; retain exact notice files; fail unapproved dependency expansion; inspect build options and binary closure per platform.
