## Reproduction

Install the pinned providers used in Milestones 03 and 04 plus the `mq`, `mail`, `codec` and `desktop` profile selections into one cumulative prefix. Keep the optional WebKitGTK profile separate. Run the glibc suites with a disposable PostgreSQL instance and `SDL_VIDEODRIVER=dummy SDL_RENDER_DRIVER=software` for headless Desktop. Run X11 and WebKitGTK fixtures with a Linux display server.

```sh
python3 tools/flint.py test --compiler dmd
python3 tools/flint.py test --compiler ldc2
python3 tools/gates.py --gate structural
python3 tools/quality.py
python3 tools/ci.py check --gate betterc
python3 tools/ci.py platform-run --target wasm32
```

The static musl replay used the pinned Alpine image and LDC with `-unittest -g -preview=dip1000 -boundscheck=on -link-defaultlib-shared=false -static -Xcc=-static`. The WASI static test uses GCC's unwinder through the same generated-recipe adjustment documented in Milestone 04. Package notes describe how to run each local protocol peer.

Both cumulative native installs verified 19 pinned provider rows and ran all four native CTests.
