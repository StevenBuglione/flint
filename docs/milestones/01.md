# Milestone 01 Linux verification

The Linux implementation of [arena](../../packages/arena/IMPLEMENTATION.md), [conc](../../packages/conc/IMPLEMENTATION.md) and [reactor](../../packages/engine-reactor/IMPLEMENTATION.md) was exercised from commit `5f835aff470bdeadcd9d79c49dae17be5fedc2c3`.

- Linux x86-64 glibc passed the three package suites with DMD 2.114.0, LDC 1.43.0 and DUB 1.43.0. Both compilers accepted the reactor API fixture and rejected the five lifetime or allocation misuse fixtures. The tests exercised real TCP loops on epoll and pinned liburing, including cancellation, EOF, partial I/O and fallback when seccomp denied ring setup.
- Linux x86-64 musl linked a static executable for all three suites. ELF inspection found no interpreter and no dynamic section. Eleven test modules passed inside the pinned Alpine container with ring setup denied and again on the host with io_uring available.
- LDC AddressSanitizer with leak detection and stack-use-after-return checks passed on all three package suites. Three native C tests passed with GCC AddressSanitizer and UndefinedBehaviorSanitizer.
- Arena BetterC passed natively on both compilers and as a wasm32 module executed by Node. The structural gate covered all three packages. The pinned formatter and D-Scanner accepted 40 files, and the 36 repository tooling tests passed.
- LDC accepted the Tier 0 source for Linux ARM64 glibc and musl. ARM64 runtime behavior and performance on the designated release runner remain unverified.

## Commands

The tests ran with the verified toolchains on `PATH`.

```sh
python3 tools/native_build.py --target linux-x86_64-glibc --library liburing --phase build --emit-dub
python3 tools/flint.py test --package arena --package conc --package reactor --compiler dmd
python3 tools/flint.py test --package arena --package conc --package reactor --compiler ldc2
python3 tools/gates.py --package arena --package conc --package reactor --gate structural
python3 tools/quality.py --path packages/arena --path packages/conc --path packages/engine-reactor
python3 -m unittest discover -s tests
```
