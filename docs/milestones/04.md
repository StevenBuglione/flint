## Reproduction

Prepare the Milestone 03 native providers plus the Linux `tui` and `wasm-host` profiles in one cumulative install prefix. The `wasm-host` profile uses Rust 1.97.0 and the pinned Wasmtime extension. Use a disposable PostgreSQL instance for the SQL, Data and Migrate integration suites.

```bash
packages=(arena conc reactor serde validate di test config log cli term style os http web security sql data migrate cache schedule actuator rpc tui widgets prompt wasm-bridge ui-signals wasi)
selection=()
for package in "${packages[@]}"; do selection+=(--package "$package"); done
python3 tools/flint.py test "${selection[@]}" --compiler dmd
python3 tools/flint.py test "${selection[@]}" --compiler ldc2
python3 tools/gates.py --gate structural "${selection[@]}"
python3 tools/quality.py
dub build --root=examples/golden-tui --compiler=ldc2
python3 benchmarks/bench-wasm/build.py --profile Oz --output artifacts/bench-wasm-Oz.wasm
```

Build the two parity fixtures in `packages/wasm-bridge/fixtures` and `packages/ui-signals/fixtures` with BetterC, then run their `parity.mjs` drivers. The integrated Chromium check uses `node packages/wasm-bridge/fixtures/check_browser.mjs <bridge-fixture.wasm> <bench-wasm.wasm>`. For static musl, run LDC with `-unittest -g -preview=dip1000 -boundscheck=on -link-defaultlib-shared=false -static -Xcc=-static` inside the pinned Alpine image. When using GCC's static unwinder for WASI, omit the generated Wasmtime `-lunwind` flag for that test link. The filesystem capability suite uses Linux `/proc/self/fd` for descriptor-backed preopens.
