## Reproduction

Run from the implementation root with the pinned compiler tools on `PATH`.

```bash
python3 tools/native_build.py --target linux-x86_64-glibc --library liburing --library libyaml --library utf8proc --phase build --emit-dub
packages=(arena conc reactor test serde validate config log di style term os cli)
selection=()
for package in "${packages[@]}"; do selection+=(--package "$package"); done
python3 tools/flint.py test "${selection[@]}" --compiler dmd
python3 tools/flint.py test "${selection[@]}" --compiler ldc2
python3 tools/gates.py --gate structural "${selection[@]}"
dub run --root=tests/integration/log-context --compiler=ldc2
(cd examples/golden-cli && dub run --compiler=ldc2 -- --name Flint)
(cd benchmarks/bench-cli && dub run --compiler=ldc2 -- --name Flint)
```

For the musl run, prepare the same three providers inside the pinned Alpine image using `linux-x86_64-musl`. The test link uses `-link-defaultlib-shared=false -Xcc=-static`. The CLI smoke uses `-O3` and `-Oz` with `-release -boundscheck=on -preview=dip1000 -link-defaultlib-shared=false -static`, then strips and runs each executable with `chroot`.
