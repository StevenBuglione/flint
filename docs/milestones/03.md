## Reproduction

Use pinned native providers from `policy/native-lock.json`, including the protobuf code generator and test fixture archive. Point the SQL, Data and Migrate `FLINT_*_PG_TEST_DSN` variables at a disposable local PostgreSQL instance. Run from the implementation root with the pinned compiler and lint tools on `PATH`.

```bash
packages=(arena conc reactor serde validate di test config log cli term style os http web security sql data migrate cache schedule actuator rpc)
selection=()
for package in "${packages[@]}"; do selection+=(--package "$package"); done
python3 tools/flint.py test "${selection[@]}" --compiler dmd
python3 tools/flint.py test "${selection[@]}" --compiler ldc2
python3 tools/gates.py --gate structural "${selection[@]}"
python3 tools/quality.py
for compiler in dmd ldc2; do
    dub build --root=examples/golden-rest-service --compiler="$compiler"
    python3 examples/golden-rest-service/verify.py examples/golden-rest-service/golden-rest-service
done
```

For the musl run, build the same providers for `linux-x86_64-musl` inside the pinned Alpine image. Run the LDC suite with static musl links and native io_uring available to the test process. Run `python3 tools/static_smoke.py --target linux-x86_64-musl --output artifacts/tasks/m3-integration/musl/static` in the same environment for the O3 and Oz binary audits and chroot smoke checks.
