The updated fixture passed 40 consecutive restarts on the measured source and on each of two Linux memory candidates.

## Strict sanitizer status

Clang 22.1.8 built the locked C providers with ASan and UBSan. The separately prepared Rust Wasmtime archive follows the host engine's ordinary build profile. Native CTest passed. The strict all-package Linux run aborted during HTTP in OpenSSL's stack callback. Additional diagnostics exposed callback type findings in two other OpenSSL files and in protobuf-c. Targeted vendor-function diagnostics allowed the affected suites to execute with the remaining sanitizer checks. The strict failure remains open.

The Actuator test also reproduced a registration-loop SIGSEGV in ten of ten runs with ASan stack-use-after-return enabled. The same binary passed ten runs with that option disabled. A private diagnostic fixture that explicitly registered the test's Registry as a GC range passed ten runs with stack-use-after-return enabled. This evidence points to GC reachability under the ASan fake stack for this test. The exact cause needs confirmation.
