# Java NIO Charset package probe

The argument count selects `CoderResult.UNDERFLOW`, `CoderResult.OVERFLOW`, `malformedForLength`, `unmappableForLength`, `UNDERFLOW.length()` (which throws `UnsupportedOperationException`), or a thrown `CoderMalfunctionError` wrapping an `Exception`, returning summary lengths or reporting whether a caught exception carries a detail message. The control throws and catches the canonical `RuntimeException` base.
