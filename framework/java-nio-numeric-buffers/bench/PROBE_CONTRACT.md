# Java NIO Numeric Buffers package probe

Allocates heap `ShortBuffer`, `IntBuffer`, `LongBuffer`, `FloatBuffer`, and `DoubleBuffer` instances, exercises `position`, `mark`, `put`, `reset`, `slice`, `asReadOnlyBuffer`, `get(int)`, and `remaining` on each, and sums their values. The baseline links `flint.java.nio.buffer` and `flint.java.nio.byteorder` without `flint:java-nio-numeric-buffers`.
