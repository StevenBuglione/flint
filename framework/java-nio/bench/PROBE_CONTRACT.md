# Java NIO package probe

The argument count selects a byte order, a relative read or write at the buffer limit, a reset without a mark, a write to a read-only buffer, or a charset coding-error action. The byte order and coding-error action branches return the name length and the control selects the same names. The exception branches throw the corresponding NIO exceptions and report whether they have a detail message. The control throws their canonical Java superclasses. Each program uses a shared RuntimeException handler. The closure probes exercise each leaf independently.
